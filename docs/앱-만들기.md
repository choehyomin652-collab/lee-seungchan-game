# 씹토체스 진짜 앱(iOS)으로 만들기 — 공동작업자 안내

게임은 HTML · CSS · JavaScript 로만 되어 있어요 (빌드 과정 없음). 그래서 **Capacitor** 같은 도구로 그대로 감싸면 iPad · 아이폰 앱이 돼요.

## 0. 게임 파일 구조 (앱에 들어가는 것)

| 파일 | 하는 일 |
|---|---|
| `index.html` · `style.css` | 화면 뼈대와 디자인 |
| `js/*.js` | 게임 전부 (자세한 지도는 `README.md`) |
| `icons/` | 앱 아이콘 (180 · 192 · 512px) |
| `js/approom.js` | 앱에서 "친구와 같이 하기" 연결 (아래 3번) |

## 1. 앱에 넣을 `www/` 폴더 만들기

```sh
sh tools/build-app.sh
```

- 게임 파일을 `www/` 로 복사해요
- 원래 인터넷(CDN)에서 받던 3D 도구(three.js r128)와 온라인용 mqtt 라이브러리를 `www/vendor/` 에 넣어서 **인터넷 없이도 열리게** 해요
- 홈 화면 앱(PWA) 설정은 진짜 앱에서는 필요 없어서 빼요
- 필요한 것: `npm` (Node.js)
- 확인함: 인터넷을 전부 막고 `www/index.html` 을 열어도 게임 · 3D · 연습장이 잘 돼요. 글꼴(Jua · Gowun Dodum)만 인터넷이 있을 때 받아요 (없으면 기기 기본 글꼴)
- `www/` 는 만들어지는 폴더라 저장소에는 올리지 않아요 (`.gitignore`)

## 2. Capacitor 로 iOS 앱 만들기 (맥 + Xcode 필요)

```sh
npm init -y
npm i @capacitor/core @capacitor/cli @capacitor/ios
npx cap init "씹토체스" com.example.ssiptochess --web-dir www   # 앱 ID 는 원하는 걸로
sh tools/build-app.sh
npx cap add ios
npx cap sync ios
npx cap open ios        # Xcode 가 열려요
```

Xcode 에서:
1. **Signing & Capabilities** → Team 에 애플 계정 고르기
   - 무료 애플 ID: 내 기기에만 설치, 7일마다 다시 설치
   - 애플 개발자 프로그램(1년 약 13만 원): TestFlight · 앱스토어 가능
2. **General → Deployment Info** → 가로 화면(Landscape Left · Right)만 켜기 (게임이 가로 화면용이에요)
3. iPad 를 연결하고 ▶ 실행

**게임을 고친 뒤 앱에 반영하기**: `sh tools/build-app.sh && npx cap sync ios` → Xcode 에서 다시 ▶

맥이 없으면: 공개 저장소라 GitHub Actions 의 macOS 서버로 빌드할 수 있어요. 다만 기기에 설치하려면 애플 서명(인증서)이 필요해서, 결국 애플 계정은 있어야 해요.

## 3. 앱에서 달라지는 점

이 게임은 원래 claude.ai 아티팩트에서 돌아가서, claude.ai 에서만 되는 기능이 있어요.

| 기능 | claude.ai 링크 | 앱 |
|---|---|---|
| 혼자 하기 · 연습장 | ✅ | ✅ |
| 친구와 같이 하기 | ✅ claude.ai room | ✅ `js/approom.js` — 무료 공개 MQTT 중계 서버 (인터넷 필요) |
| 모두에게 보이는 카드 · 배경 사진 | ✅ | ❌ (각자 기기에만 저장) |
| 미리 넣은 친구 카드 사진 | ✅ | ❌ 친구 얼굴 사진이라 저장소에 없어요. 앱에서는 3D 캐릭터 그림이 나와요 |

**친구와 같이 하기 (앱)**
- `js/approom.js` 가 claude.ai room 과 같은 모양(`peers` · `presence` · `onPeers`)을 공개 MQTT 서버로 만들어요. `js/online.js` 는 그대로 써요
- 서버 목록: `broker.emqx.io` → `broker.hivemq.com` → `test.mosquitto.org` (안 되면 다음 서버)
- 2초마다 내 상태를 보내고, 7초 동안 소식이 없으면 나간 걸로 봐요
- ⚠️ 아직 실제 기기 두 대로 시험하지 못했어요. 먼저 꼭 확인해 주세요
- ⚠️ 공개 서버라 같은 방 코드를 아는 사람은 이름과 배치를 볼 수 있어요. 앱스토어에 정식으로 낼 거면 전용 서버(직접 만든 MQTT · Firebase · Supabase 등)로 바꾸는 걸 추천해요. `APP_BROKERS` 만 바꾸면 돼요

## 4. 앱스토어에 낼 때 미리 생각할 것

- **실제 친구들의 이름 · 얼굴**: 게임 캐릭터가 실제 반 친구들이에요. 공개 앱스토어에 내려면 친구들(과 보호자)의 동의가 필요하고, 비공개(TestFlight · 내 기기)로 쓰는 게 안전해요
- **앱 이름**: "씹토체스"는 비속어로 읽힐 수 있어서 심사에서 문제가 되거나 연령 등급이 올라갈 수 있어요
- **18세 미만**: 애플 개발자 프로그램은 만 18세 이상만 가입할 수 있어요 (보호자 명의로 가입)
- **심사 4.2 (웹 포장 앱)**: 게임 파일이 앱 안에 다 들어 있고 인터넷 없이도 돌아가서 문제될 가능성은 낮아요
