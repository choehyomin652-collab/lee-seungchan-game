# 씹토체스

반 친구들이 주인공인 롤토체스 스타일 오토배틀 게임이에요.
`index.html`을 브라우저로 열면 바로 돼요 (3D 도구를 인터넷에서 받아오므로 처음 한 번은 인터넷이 필요해요).

## iPad · 아이폰 앱으로 설치하기
1. Safari 로 https://choehyomin652-collab.github.io/lee-seungchan-game/ 를 열어요
2. 공유 버튼(네모에 위쪽 화살표) → **홈 화면에 추가**
3. 홈 화면의 씹토체스 아이콘으로 열면 전체 화면 앱처럼 돼요. 한 번 연 뒤에는 인터넷이 없어도 열려요

앱에서는 혼자 하기 · 연습장 · 친구와 같이 하기(공개 중계 서버)가 돼요.

## 진짜 앱(iOS)으로 만들기
공동작업자 안내: [`docs/앱-만들기.md`](docs/앱-만들기.md) — `sh tools/build-app.sh` 로 앱에 넣을 `www/` 폴더를 만들어요.

## 파일 지도 — 내가 고칠 파일 찾기

| 하고 싶은 일 | 고칠 파일 |
|---|---|
| 친구 추가 · 코스트 · 특성(시너지) 바꾸기 | `js/friends.js` |
| 친구 스킬 · 기본 공격 외침 · 소환수 | `js/skills.js` |
| 친구가 들고 있는 무기 · 날아가는 공격 모양 | `js/weapons.js` |
| 증강(2-1, 3-2, 4-2에서 고르는 보너스) | `js/augments.js` |
| 4인 합체로봇 | `js/robot.js` |
| 버튼 · 색 · 글자 크기 · 화면 배치 | `style.css` |
| 전투 계산(공격력, 이동, 피해) | `js/battle.js` |
| 상점 · 합성 · 라운드 진행 · 컴퓨터 반 | `js/game.js` |
| 3D 경기장 · 친구 모양(머리, 옷) · 이펙트 | `js/render3d.js` |
| 캐릭터 그리기 도구(만화 음영 · 외곽선 · 얼굴 그림 · 머리카락 · 부품 합치기) | `js/figure.js` |
| 터치 · 정보창 · 설정 메뉴 | `js/ui.js` |
| 레벨 확률 · 몬스터 · 기본 숫자 | `js/constants.js` |
| 효과음 | `js/sound.js` |
| 친구와 같이 하기(온라인 방 · 실시간 대전) | `js/online.js` |
| 올린 사진(카드 · 배경)을 모두에게 보이게 | `js/photos.js` |

처음이라면 **`js/friends.js`, `js/skills.js`, `js/weapons.js`** 세 개만 보면 돼요.
세 파일 모두 맨 위에 쓰는 법이 적혀 있어요.

## 예시

**스킬 숫자 바꾸기** — `js/skills.js`에서 친구 이름을 찾아 숫자만 고쳐요.

```js
"전하율": { s: "약점 공략", ... dealDamage(B, u, t, 140 * P, "skill") ...
```
`140`을 `200`으로 바꾸면 피해가 커져요.

**새 친구 추가하기**
1. `js/friends.js`의 `DEFS`에 한 줄 추가: `{ n: "이름", c: 2, k: "돌격대", t: ["운동광"] }`
2. `js/skills.js`의 `SK`에 `"이름": { s: "스킬 이름", d: ..., run(...) { ... } }` 추가
3. `js/weapons.js`의 `WEAPONS`에 `"이름": { n: "무기 이름", build(e) { ... } }` 추가 (없으면 무기 없이 나와요)

## 같이 작업할 때 지켜요

- **자기 파일만** 고쳐요. 다른 사람 파일은 건드리지 않아요. 그러면 서로 덮어쓸 일이 없어요.
- 올리기 전에 `index.html`을 열어서 한 판 해봐요. 빨간 "오류가 났어요" 글자가 뜨면 되돌려요.
- 같은 파일을 두 명이 고치면 한 명이 나중에 합쳐야 해요. 겹치지 않게 미리 말해요.
- 친구 얼굴 사진을 코드에 넣지 않아요. 사진은 게임의 설정(톱니바퀴) 메뉴에서 올려요.
  게임 페이지를 고칠 수 있는 사람이 올리면 링크를 여는 모두에게 보이고, 다른 사람이 올리면 자기 기기에만 저장돼요.
  모두에게 보이는 사진은 본인이 괜찮다고 한 사진만 올려요.
- 친구를 놀리는 말이나 기분 나쁠 수 있는 이름은 쓰지 않아요.

## Claude로 고치고 올리기

> "js/skills.js에서 박준서 스킬을 더 세게 바꿔줘. 그 파일만 고쳐서 같은 아티팩트에 올려줘."

이렇게 파일 하나만 말하면, 올릴 때 나머지 파일은 그대로 두고 그 파일만 바뀌어요.

## 파일 순서 (바꾸지 마세요)

`index.html`이 `js/friends.js → skills → augments → constants → game → battle → robot → weapons → sound → online → photos → figure → render3d → ui` 순서로 불러와요.
"친구와 같이 하기"는 claude.ai 아티팩트로 올린 페이지에서만 켜져요 (`index.html`을 그냥 열면 "혼자 하기"만 돼요).
같이 할 친구는 게임 주인이 아티팩트의 공유 메뉴에서 **이메일로 초대**해야 해요. "링크가 있는 누구나"로 연 사람은 실시간 방에 못 들어와요.
새 파일을 만들면 `index.html`에 `<script>` 줄을 같은 방식으로 추가해야 해요.
